# Product Finder

Mini Project 3-4 (MP3-MP4) for CSE-2340: Software Development I.

## About the Project
A simple product explorer web application built with HTML, CSS, and JavaScript. It fetches product data from the DummyJSON Products API and lets users search, filter by category, sort by price, view details, and save favorite items using Local Storage.

## Features
- Fetches products dynamically using `fetch()` and `async/await`
- Shows loading, error (with retry button), and empty states
- Search products by title or description
- Filter products by category and sort by price
- View full product details in a popup modal
- Save and remove products in Local Storage (persists after page refresh)

## API Used
- https://dummyjson.com/products

## How to Run
1. Download or clone the repository.
2. Open `index.html` in any web browser.
